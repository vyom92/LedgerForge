# Future work

This is the prioritized open queue, not implementation authority. Check [scope decisions and rejections](SCOPE_DECISIONS.md) before adding work. [PROJECT_STATE](PROJECT_STATE.md) owns accepted product facts; the [current roadmap](Sprint%20roadmap/LedgerForge_Roadmap_Sprints_80-89_Current.md) owns sequence and selected scope. Recording, approval, readiness, scheduling and execution are separate.

Order inherits [Guide rules A/B](Project_Guide.md#documentation-order): P0 → P3, then natural FW-ID including suffixes unless an explicit accepted relative ranking exists. State does not reorder priority. Parked items follow priority/ID order and are revisited only for their recorded condition.

**States:** Needs review = one unresolved discovery/decision boundary; Ready = bounded enough for selection, never authorization; Blocked = named missing prerequisite; Parked = explicit deferral and revisit condition; In progress = selected work still awaiting acceptance, including paused work. The ID remains until acceptance. **Kinds:** Defect, Feature, Idea, Maintenance. An observation is not a verified defect.

**Basis:** “Recorded proposal/idea/remainder” preserves an existing card without inventing its original author or decision date.
