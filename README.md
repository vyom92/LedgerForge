# LedgerForge

LedgerForge is a personal, single-user macOS application for bringing bank, card and investment statements into one local ledger and planning a monthly budget.

Its optional Gmail connection uses Google's read-only Gmail permission to find statement messages and retain original attachments for local import. It cannot send email, delete messages, change labels or mark messages as read. The application and its Google OAuth connection are maintained for the owner's personal use.
